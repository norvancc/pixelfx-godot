# Code of Conduct

Be respectful, constructive and patient. Review ideas and code, not people. Welcome contributors with different experience levels and backgrounds.

Harassment, threats, discriminatory language, sexualized conduct, doxxing and publishing private information are not acceptable. Do not use issues or pull requests for spam or personal attacks.

Maintainers may edit or remove abusive content, close disruptive discussions or restrict participation. Enforcement should be proportionate and consider context. This policy applies to this repository's issues, pull requests and related project discussions.

For harmful content, use GitHub's **Report content** action. Do not post sensitive reports or personal information in a public issue. GitHub can handle confidential abuse reports through its reporting process.

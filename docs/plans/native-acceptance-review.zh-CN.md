# 新增原生效果优化与验收：2026-11-10

通用迁移执行层的秒级卡顿已大幅降低，新增效果仍未整体达到实时性能门槛。源码覆盖为 244/244 个算法、245 个预设；完整验收保持 52/244。当前代码不会因为抽样像素通过就自动提升完整验收计数。

固定上游为 `a84159688af3ca37a4be05a0d422b94451b2e24e`。本轮深入检查 B2 最后八项：Fire ring、Blessing、Divine shield、Halo、Heal、Resurrection、Freeze、Frost nova；其他新增项进行生命周期与热点参数抽样。本轮可机读记录见 [native-review.json](../../addons/pixelfx/validation/native-review.json)。

## 修复内容

- 依赖延迟解析和局部数值函数编译，减少通用语义分派；粒子、天气、烟雾、几何、角色像素、字体和过场的热点循环直接执行原生运算。爆炸辅助函数中的纯像素着色回调，在每次同步绘制开始时读取只读闭包变量，避免逐像素重复解析作用域。
- 合成器跟踪实际写入区域；光照通道使用数学查表，保留原始像素结果。仅缓存确定性的数学格点、几何和运行时生成的共享帧，没有引入预录画面。
- `switch` 内 `continue` 转发、数组成员解构写回、数字对象键、Uint32 读取、Map/Set 数字键、缺失 Map 值比较、数字一元转换、闭包捕获与 lerp 参数重复求值均已修复，并用独立 Node oracle 与 Godot fixture 回归。
- 天气光晕恢复上游的本地像素采样方式；旋转、小数位移和裁剪使用原规则。默认位置可使用等价的直接缓冲路径。此前 10 个天气效果的 60 个参数失败已消除。
- 黑洞盘面、风暴云的 Float32 场、落叶叶片、能量星轮廓与光线，以及暗系环带和烟团增加原生计算，保留原有采样与绘制顺序。
- 石块、石刺和荆棘保留原有轮廓、刻面、裂纹和描边；挥砍的几何过滤移入原生循环；雨雾逐行合成，减少每像素闭包调用。
- 对新增路径的烟雾与尘埃使用有明确适用区间的 fdlibm/V8 衰减计算，避免平台 `pow(k, 1.3)` 的末位差异经半透明叠加放大。2048 个独立 V8 数值样本的最大差为 1 ULP；高精度常量用位模式初始化。该数值检查不替代像素门槛，第三方许可已保留。
- 修复编辑器切换资源时 Inspector 持有旧资源 ObjectID 的生命周期问题，切换和退出时先脱离 Inspector。
- 完整图鉴按真实经过时间推进，避免慢帧把播放速度一起拖慢；界面同时显示 CPU 耗时与场景 FPS。

没有降低画质、改变元数据帧率或放宽全局像素容差。默认门槛仍为最大通道差 1/255、变化通道字节不超过 20。Divine shield 的一个既有案例锁定 21 个 RGB 字节相差 1，alpha、误差矩形和总误差均单独校验。

## 性能

## 复现

```sh
python3 tools/pixelfx/check_native_semantics.py
python3 tools/pixelfx/check_native.py /absolute/path/to/pinned/upstream --expanded --survey --performance
```

第二条在 33.3 ms CPU p95 预算失败时返回非零，仍保留实测结果。全目录三点性能采样使用 `tests/pixelfx/benchmark_native_catalog.gd`，带效果过滤时写入单独的 `performance-native-catalog-selected.json`，避免覆盖全目录报告。可见窗口实测使用 `tests/pixelfx/benchmark_native_realtime.gd`；编辑器验证使用 `python3 tools/pixelfx/check_editor.py`。

已有发布范围检查仍使用 `python3 tools/pixelfx/check.py`；`PIXELFX_FULL_NATIVE=1` 会将新迁移项的深入检查与性能预算一并加入。本轮按用户决定结束追加验收并交付主分支；已知问题按实际使用反馈继续修复。源码交付不另建发行版本。

交付 CI 的启动检查曾因只取开头与 45% 生命周期，漏过 `moves/dash-strike` 的短促斩击而误报空白。检查脚本补取 17% 时刻；该项定向启动检查通过（0.391 秒有 13348 个非空通道值），不放宽空白判定、不改效果算法。

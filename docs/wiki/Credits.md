# 来源与许可

本项目是 PixelFX 的独立 Godot 移植，不是原作者的官方发行版。

- 原始项目：[patch-gg/pixelfx](https://github.com/patch-gg/pixelfx)，作者 **Patch / Hugo Duprez**。
- 固定版本：PixelFX **0.3.0**，commit `a84159688af3ca37a4be05a0d422b94451b2e24e`。
- 插件与原始算法采用 **MIT**；再分发时保留版权与许可。
- 少量衰减数学保留 fdlibm / V8 的独立许可，见[第三方许可](https://github.com/norvancc/pixelfx-godot/blob/main/addons/pixelfx/native/third_party/fdlibm-LICENSE)。

每个原生模块保留上游源码路径。原始文件哈希与来源清单见 [provenance.json](https://github.com/norvancc/pixelfx-godot/blob/main/addons/pixelfx/provenance.json)、[native sources](https://github.com/norvancc/pixelfx-godot/blob/main/addons/pixelfx/native/sources.json) 与 [NOTICE](https://github.com/norvancc/pixelfx-godot/blob/main/NOTICE.md)。

宣传页的逐项动画录自真实 Godot 输出。UI 构图参考 [Pinterest Dark RPG UI](https://www.pinterest.com/pin/989666086888419457/)，参考图的角色和插画没有打包。森林素材使用 [Magical Road / Luis Zuno](https://opengameart.org/content/magical-road-pixel-art-environment)，CC0；夜景改色和门廊构图由本项目制作。首屏角色来自 MIT 上游的 stockActor 像素数据。Pixelify Sans 与 DM Sans 字体保留 SIL Open Font License。

## 原版一致性

参考数据由未修改的 PixelFX 0.3.0 JS 代码生成，固定提交与源文件哈希见 provenance.json。
74 组效果采样 + 4 组 Painter 原语，共 78 组：72 组 RGBA 字节完全一致。
其余 6 组分别有 11、5、1、1、3、1 个通道字节相差 1/255，无更大误差。
每张效果样本为 224×224×4 字节；不声称全量像素完全相同。
RNG 的 32 位整数序列、负种子/大种子、噪声和分形函数也已核对。

## 证据边界

API 目标为 Godot 4.3+，当前只完成上述 4.7.2 环境验证。
提供 4.3 Linux CI 配置，但未在远端执行；其他引擎版本、平台和渲染器未验收。
视频是正常速度演出证据，不是多实例实时性能证明。
缓存命中后的 CPU 基准不包括完整场景 GPU 成本；不同参数的冷生成仍约 20 ms/个，
应在游戏加载阶段预热常用预设。用户审美验收仍以实际查看为准。

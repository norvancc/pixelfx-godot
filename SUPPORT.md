# Support

For usage questions, open a GitHub issue using the question template. For bugs, include the Godot version, renderer, OS, addon release version or exact source commit, effect/preset, minimal reproduction and relevant logs. Remove private paths, tokens and unrelated game assets first.

The latest release 0.2.0 contains five algorithms; the main branch contains 244 algorithms / 245 presets, with 52 fully accepted and 192 pending full acceptance. State whether you installed a release archive or copied the addon from source. For current migration coverage, consult the [roadmap](ROADMAP.md) and [effect catalog](addons/pixelfx/docs/CATALOG.md).

Check [README](README.md), [API](addons/pixelfx/docs/API.md), [authoring](docs/AUTHORING.md) and [known limits](addons/pixelfx/docs/PERFORMANCE.md).

This is an unofficial port; report Godot-specific problems here rather than assuming the upstream project maintains this addon. Security reports follow [SECURITY.md](SECURITY.md). Maintenance is best-effort and release dates are not guaranteed.

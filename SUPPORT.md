# Support

For usage questions, open a GitHub issue using the question template. For bugs, include the Godot version, renderer, OS, addon version, minimal reproduction and relevant logs. Remove private paths, tokens and unrelated game assets first.

Check [README](README.md), [API](addons/pixelfx/docs/API.md), [authoring](docs/AUTHORING.md) and [known limits](addons/pixelfx/docs/PERFORMANCE.md).

This is an unofficial port; report Godot-specific problems here rather than assuming the upstream project maintains this addon. Security reports follow [SECURITY.md](SECURITY.md). Maintenance is best-effort and release dates are not guaranteed.
